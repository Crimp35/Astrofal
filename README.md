# Astrofal

Astrofal is a sample Flutter application demonstrating a multi-platform fortune
telling experience. The app includes coffee reading, tarot cards,
numerology, and a question–answer style fortune. All readings are powered by
an AI backend (e.g. OpenAI) and integrate with Firebase for storage and auth.

## Disclaimer

This project is **for entertainment purposes only**. The fortune telling
features do not provide factual or professional advice. Users are responsible
for their own decisions and should consult qualified professionals for real
life concerns. No real psychics or astrologers are involved.
